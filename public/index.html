Watch video in your terminal

framefeed streams real video as Sixel pixels over plain HTTP — 800×450 px at 24 fps. No browser player, no app install — just a Sixel-capable terminal and a single curl command.

terminal
$ curl https:///<slug>

The host resolves to this deployment immediately; the slug picks up a real clip once the catalog loads. Paste the command into Windows Terminal 1.22+, WezTerm, Konsole, or iTerm2 — Sixel is required for the pixel stream, and it works over SSH too.

How it works

  1. 01

    Copy the command

    Open any catalog card and copy the curl command.

  2. 02

    Run it in your terminal

    Run it in a Sixel-capable terminal: Windows Terminal 1.22+, WezTerm, Konsole, or iTerm2 (over SSH works too). Frames play live as they arrive.

  3. 03

    Press Ctrl+C to stop

    Streams are pre-encoded Sixel frames, not browser video. Ctrl+C stops playback and leaves your shell usable.
